## What this list is for

Not recorded. One paragraph. What kind of playthrough is this build serving,
what is deliberately out of scope, and what the visual and gameplay target is.
Write it now because in eight months it stops being obvious, and every later
decision gets argued against it.

## Snapshots

Newest folder in `snapshots/` is the current recorded state. Each one holds
`SUMMARY.md` for reading, `snapshot.json` for machines, and `raw/` with the
untouched MO2 profile files.

Snapshots are immutable. If something changed, take a new one.
