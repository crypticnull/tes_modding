# Research

Long-form notes on the bigger install questions. One file per topic, named
`<game>-<topic>.md`, for example `skyrim-community-shaders-vs-enb.md`.

## Why this exists as prose

A link dump is worthless in six months when half the pages are gone and the rest
have been edited. Every entry here summarises the actual finding in its own
words first, then cites where it came from, so it still works when the source
does not.

## Shape of an entry

Start with the question in one line. Then the answer as it stands today, with a
date on it. Then what it depends on, since most modding answers are conditional
on engine version, script extender build, VRAM or which other overhaul is in
play. Then the sources, each with a one-line note on what it actually said.
Then a status of settled, provisional or stale.

Mark an entry stale rather than deleting it. Knowing that an approach was
correct in 2026 and is not any more is itself worth keeping.

## Topics worth writing up early

Nothing recorded yet. Likely first candidates are the script extender and
runtime version situation for each game, the shader and lighting stack choice,
the load order and conflict resolution approach, and whichever install
originally took the longest to get stable.
