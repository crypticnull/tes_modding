# Goals

Where the lists are headed. This is the file that stops a session six months
from now from optimising for the wrong thing.

Anything here that is still marked "not recorded" is a question for Matt, not a
gap to fill with a guess.

## Skyrim

Not recorded. Answer these and the rest of the archive gets a lot more useful.

1. What is the playthrough this build is for, and roughly how many hours is it
   meant to survive without a rebuild.
2. Visual target. Vanilla-plus, heavy overhaul, photoreal, stylised, and whether
   ENB or Community Shaders is the path.
3. Gameplay target. Vanilla combat, a combat overhaul, a survival layer, a
   requiem or similar total conversion.
4. What is explicitly out of scope, because the out-of-scope list saves more
   time than the wishlist.
5. Stability floor. What counts as acceptable, a crash an hour or none at all.

## Oblivion

Not recorded. Same five questions. Also worth pinning down early whether this is

## Archive goals

These are settled.

- Every material change to either list leaves a snapshot and a changelog line,
  so the state is always reconstructible from git.
- Research that took more than twenty minutes gets written down in
  `docs/research/` with sources summarised, not linked and forgotten.
- Any decision that a future session would plausibly reverse gets a record in
  `docs/decisions/`, so it gets reversed on purpose rather than by accident.
- No chat session ever has to be told the modlist contents by hand again.

## Non-goals

- Not publishing or distributing either list.
- Not automating installs. MO2 stays the tool, this repo stays the memory.
- Not mirroring mod files into git.
